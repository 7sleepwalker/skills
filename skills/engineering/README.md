# Engineering

Skills for daily code work.

## Model-invoked

Reachable by the model or by typing the name.

- **[code-quality](./code-quality/SKILL.md)**: PR-focused review against the repo's own discovered standards, plus overcomplication, logic-bug risk, and whether the diff matches the PR description and ticket. Fans out across parallel agents, writes an HTML report, can post to the PR and apply safe fixes.
- **[diagnosing-bugs](./diagnosing-bugs/SKILL.md)**: Six-phase diagnosis loop for hard bugs and performance regressions: build a tight feedback loop that goes red on this bug, minimise, hypothesise, instrument, fix with a regression test, clean up.
